Maximum demand · IEC method (ku / ks)

How the demand is calculated

Connected load is converted to expected maximum demand with a utilisation factor ku per load and a coincidence factor ks per board. Results size feeders, boards, transformers and generators.

  1. Installed apparent power per load. Pa = Pn / (η · cosφ) kVA. Motor ratings are shaft output, so η and cosφ are required. Active power P = Pn/η, reactive Q = P · tanφ. Sourced EIG
  2. Maximum utilisation. Pa,max = Pa · ku · n. Typical ku: motors 0.75 (average industrial), incandescent lighting 1, EV charging 1. Sourced EIG
  3. Board demand. S = ks · Σ Pa,max. Mixed power factors are summed as complex power, S = √((ks·ΣP)² + (ks·ΣQ)²). The arithmetic kVA sum is shown beside it and can be chosen as the design basis. Sourced EIG Derived
  4. Hierarchy. Each board applies its own ks to the demand of the loads and sub-boards it feeds. ks is never applied twice to the same load.
  5. Extension factor. S,design = S · k,ext with k,ext ≥ 1. User input only. Assumed
  6. Design current. Three-phase Ib = S·10³ / (√3·U); single-phase Ib = S·10³ / V. Sourced EIG
  7. Phase balance. Single-phase loads are summed per phase. Unbalance (Imax − Iavg) / Iavg, checked against your limit. Assumed method

Non-simultaneous and standby loads

Give loads that never run together the same exclusive group (for example season) and different options (winter, summer). On each board only the option with the larger demand counts. Standby loads count toward connected load but not demand.

What this version does not cover yet

  • No national demand-factor tables are built in as authoritative. MNS and PUE tables for Mongolia were not found during research. Residential per-dwelling tables (BS 7671 App. 4, SP 256) are not included.
  • Lift starting current (Ib + ⅓ Istart), motor starting dip, harmonic neutral current and cable sizing are later modules.
  • EIG Fig. A15 (workshop example) is not a test case yet because its itemised values could not be read.
